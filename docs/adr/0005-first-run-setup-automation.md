# First-Run Setup Automation and State Tracking

Decided to automate container initial setup including CBM configuration (auto_index, auto_watch, limits) and skills setup (opencode run "setup-matt-pocock-skills"), tracking completion via setup-complete flag in sandbox_config.json. CBM configuration runs non-interactively; skills setup uses an attached terminal so interactive prompts receive input. Each stage is marked complete only after success, offering granular recovery options for partial failures without repeating completed stages. This reduces manual configuration while ensuring consistent environment setup across projects.
