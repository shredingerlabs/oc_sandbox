# First-Run Setup Automation and State Tracking

Decided to automate container initial setup including CBM configuration (auto_index, auto_watch, limits) and skills setup (opencode run "setup-matt-pocock-skills"), tracking completion via staged flags in sandbox_config.json. CBM configuration runs non-interactively; skills setup runs as a direct `podman exec -it` command so the attached terminal carries stdin and stdout to the interactive command. Each stage is marked complete only after success, and setup_complete is written only after both stages succeed. Failed stages retain the existing retry path without repeating completed stages. This reduces manual configuration while ensuring consistent environment setup across projects.
