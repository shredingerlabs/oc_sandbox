# First-Run Skills Setup as Interactive TUI Session

The skills stage of the first-run setup used `opencode run "setup-matt-pocock-skills"`, but `opencode run` is strictly non-interactive, so questions asked by the setup skill could never reach the user and the stage could not complete its job. Decided to launch the skills stage as an interactive TUI session instead: `opencode --prompt "run skill setup-matt-pocock-skills" -m "$OPENCODE_MODEL"` via `podman exec -it`, with the model coming from the `OPENCODE_MODEL` variable (`opencode/big-pickle`, a free OpenCode Zen model that requires no API key). The prompt auto-submits when the TUI is ready. This supersedes the skills stage of ADR-0005 (headless `opencode run`); the CBM stage remains non-interactive. Trade-off accepted: a clean TUI exit (code 0) marks `setup_skills_complete` even if the user quit early — recovery is possible via the existing setup recovery flow. The default model in `opencode.json` is deliberately untouched; BigPickle is used for the setup session only.
